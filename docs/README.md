# Project Mongrel Documentation

Project Mongrel is a Telegram-first investigation platform for authorized security assessment workflows. It coordinates scan evidence, uploaded findings, risk analysis, grounded AI assessment, and report generation around investigations.

This documentation set is intended for future developers, reviewers, and release maintainers.
