# Roadmap

Project Mongrel development is organized into phases. Completed work should remain visible so future changes can be reviewed against the product foundation.

## Phase 1 - Foundation

Status: Completed

Completed missions:

- Telegram UX
- Nmap integration
- Nuclei integration
- Upload handling
- SQLite persistence
- Comparison engine
- Risk engine
- Reports
- AI assessment
- Timeline
- Security audit
- Documentation

Phase 1 established Project Mongrel as a Telegram-first investigation platform with persistent evidence, repeatable reporting, and a local release audit process.

## Phase 2 - Intelligence

Status: In progress and planned

- Mission 9.9: Product security hardening and audit pipeline. Status: Completed.
- Mission 10: Intelligence layer expansion. Status: Planned.
- Mission 11: Advanced evidence correlation. Status: Planned.
- Mission 12: Observation Agent integration. Status: Planned.
- Mission 13: Attack path analysis. Status: Planned.
- Mission 14: Dashboard and review workflows. Status: Planned.
- Mission 15: Historical trends and release-scale reporting. Status: Planned.

Phase 2 focuses on moving from tool execution and reporting toward evidence correlation, long-term context, and higher-confidence investigation support.
